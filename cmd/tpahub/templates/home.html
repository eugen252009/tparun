Start here

From clean machine to working tools.

Run this on Debian 12 amd64 with a user that can use sudo. Review the installer before running it.

curl -fsSL https://tpa.run/install.sh -o /tmp/tpahub-install.sh
sudo bash /tmp/tpahub-install.sh
sudo apt-get install -y mema bloom mema-go mema-bun
sudo mema install go 1.26.5
sudo mema install bun 1.3.14

The installer configures the signed APT source and installs tpahub. Mema manages the runtimes; Bloom provides reusable capability discovery.

One path, three roles

The pieces stay simple.

TPA Hub

Provides signed Debian package repositories and the public installation path.

Mema

Installs and manages developer runtimes and tools without replacing the package workflow you already know.

Bloom

Helps discover reusable capabilities and inspect what they provide.
