Use storage for the bytes that need a home.

Nano uses the same core TPA Hub capabilities as the larger plans. Its difference is capacity, not functionality.

If software already has a reliable upstream, you may not need to mirror its entire payload into TPA Hub.

5 MB sounds small. Is it?

5 MB storage
12 GB yearly repository egress

For lightweight packages, it can represent a lot of software. At roughly 2 KB per recipe, 5 MB could hold about 2,500 recipe-sized packages. A completely full 5 MB repository could theoretically be transferred in full roughly 200 times within the 12 GB yearly egress allowance.

These are simple illustrative estimates, not guarantees. Actual usage depends on package sizes, repository metadata, update patterns, HTTP overhead, APT caching, and client behavior. Your mileage may vary.

Recipes instead of mirrors

Mema is an independent optional tool that provides a reusable installation and version-management runtime. A small application-specific recipe tells Mema how to retrieve and install software from its existing upstream.

The large payload is still downloaded by the user's machine. The efficiency is that it does not need to occupy TPA Hub storage or pass through TPA Hub when a suitable upstream already exists.

Real example: Neovim

about 2.4 KBmema-neovim_0.12.5_amd64.deb
the recipe package, not Neovim itself

Mema retrieves the actual Neovim 0.12.5 release from its upstream and installs it. This recipe passed through Mema's generic repository build and was independently installed successfully in clean Debian.

One runtime, many small recipes

The Mema runtime itself is a full package—about 1.8 MB for mema_0.2_amd64.deb—and is installed once. Additional recipes can remain small. The same generic mechanism is used across tools including Go, Rust, Python, Node, Bun, Deno, Wayland, wlroots, Sway, and Neovim.

When you need more hosted storage

Recipes are optional. Nano also works with ordinary .deb publishing. If you need TPA Hub to own private binaries, internal software, large custom packages, or artifacts without a dependable upstream, larger plans are the natural fit.
