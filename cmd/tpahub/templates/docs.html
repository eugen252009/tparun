The practical guide

From .deb to apt install.

Install public packages without an account, or sign in to publish your own.

Install the client

These commands target Debian 12 amd64. Run them with a user that can use sudo; in a root shell, omit sudo.

sudo apt-get update
            sudo apt-get install -y ca-certificates curl gpg less
            curl -fsSL https://tpa.lupricht.net/install.sh -o install-tpahub.sh
            less install-tpahub.sh

Inspect the installer and verify the signing key below before running it. The installer configures a signed APT source and installs tpahub.

Verify trust material

Download and inspect the public signing key. Compare its primary fingerprint with the expected value before trusting it.

curl -fsSL https://tpa.lupricht.net/tpahub.asc -o tpahub.asc
            gpg --show-keys --fingerprint tpahub.asc

Expected: 42313D9F5F1F319AB5A18F6122380CEE20D731C6

Do not continue if the fingerprint differs. The installer embeds the signing key; check that it matches too. This website and download share an HTTPS trust origin—use an independently trusted fingerprint if your security policy requires one.

Sources use signed-by= with keys under /etc/apt/keyrings. Do not use apt-key or disable APT signature verification.

After checking the installer and signing key, install the client:

sudo bash install-tpahub.sh

Check client compatibility

The public client release may lag behind the server. Older clients default to localhost and do not resolve public repository names. This is an open onboarding limitation, not a problem with your installation.

dpkg-query -W tpahub

For a client supporting discovery, use:

tpahub repo list --public --server https://tpa.lupricht.net

If discovery is unavailable, open the public repository directory. Find the desired repository name and copy its id. Add it with the compatible command:

sudo tpahub repo add REPOSITORY_ID --server https://tpa.lupricht.net

Use the same ID for later removal. Repository names are exact and may be ambiguous; an ID disambiguates them. Public discovery does not expose private repositories.

Install public packages

No publisher login is required. With a client supporting name resolution:

sudo tpahub repo add mema-public --server https://tpa.lupricht.net
            sudo tpahub repo add bloom-public --server https://tpa.lupricht.net
            sudo apt update
            sudo apt install mema bloom

For older clients, add each repository by its directory ID as described above, then run the same APT commands.

Mema and Bloom are independent tools. Install either or both; Bloom does not require Mema.

Try Bloom

Find the minimum of [31, 12, 91, 4, 28]. The input below encodes unsigned 32-bit little-endian integers:

mema list
bloom search "math min u32"
bloom describe math.min.u32
printf '\\037\\000\\000\\000\\014\\000\\000\\000\\133\\000\\000\\000\\004\\000\\000\\000\\034\\000\\000\\000' |
  bloom run math.min.u32 --input-format u32le --output-format text

Expected output: 4. Bloom is an independent tool; it does not require Mema.

Publish your package

Publishing requires an account with an active publishing entitlement. Account creation alone does not promise paid capacity. Check your account and plan availability.

tpahub register --server https://tpa.lupricht.net
            tpahub login --server https://tpa.lupricht.net
            tpahub repo create tools --public
            tpahub publish tools ./my-package_1.0.0_amd64.deb
            tpahub status JOB_ID

Replace the package path with your build output and JOB_ID with the returned job ID. Wait for successful publication before configuring consumers.

On the consuming machine, add the repository's ID, then install:

sudo tpahub repo add REPOSITORY_ID --server https://tpa.lupricht.net
            sudo apt update
            sudo apt install my-package

The CLI saves the server selected during login. Supported newer clients also accept TPAHUB_SERVER; an explicit --server takes precedence. Local development servers remain supported.

Private repositories

Repositories are private unless created with --public. As the publisher, create a reader token: 

tpahub repo create private-tools
            tpahub repo token create private-tools workstation

On the consuming machine:

sudo tpahub repo add REPOSITORY_ID --token READER_TOKEN --server https://tpa.lupricht.net

Reader tokens authorize downloads from one repository, not administration or publishing. Treat them as secrets; avoid shared shell histories. APT credentials are written to a restricted file under /etc/apt/auth.conf.d.

Usage & limits

Published storage

Storage is the sum of canonical published .deb payload sizes across an account's repositories. Metadata, temporary workspaces, caches, and historical uploads are excluded from that measurement. Technical staging and request limits still apply independently.

Repository egress

Actual delivered package and repository metadata body bytes count, including partial range responses. Website pages, uploads, API calls, HEAD and 304 responses do not count. Public and private delivery use the same accounting.

Nano aggregates egress over its anniversary-based entitlement year. Active transfers finish normally at the annual threshold; new package downloads are rate-limited. Metadata remains available and continues to count.

Billing status

Account usage previews are operational information, not invoices. Stripe Sandbox checkout, where enabled, is test-only. Standard, Pro, live usage-based charging, and future spend controls are not available purchase options.
