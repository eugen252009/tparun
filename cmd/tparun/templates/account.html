Publish from your terminal.

The CLI creates repositories, publishes packages, and manages reader tokens. Inspect a repository before asking a machine to trust it.

tparun login                 # uses the configured server
tparun login tpa.run        # defaults to https://tpa.run
tparun create myrepo
tparun stage ./package.deb
tparun status
tparun publish https://tpa.run/r/eugen/my-package

Repositories are private by default. Publishing requires an active entitlement.
