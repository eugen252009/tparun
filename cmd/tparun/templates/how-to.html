Install TPA.run

The public CLI installation flow is pending. You can inspect the signed source file, but its referenced repository and bootstrap alias are not active, so do not add it to APT yet.

curl -fsSL https://tpa.run/tparun.sources -o /tmp/tparun.sources
echo 'd705adf0cc1943be3c46e11bab749710caaaf29e1d88fe956cdcd848cbfb073d  /tmp/tparun.sources' | sha256sum -c -
sed -n '1,12p' /tmp/tparun.sources

Inspect a repository before adding it

Repository configuration is a trust decision. Start with inspection; this command does not write system APT configuration.

tparun show https://tpa.run/r/eugen/dev-tools

Check the publisher, repository identity, visibility, signing information, and package list. If the provenance is clear and you intend to trust the source, continue to configuration.

Install a package

After inspecting and choosing a repository, add its canonical URL and install the package it publishes.

sudo tparun add https://tpa.run/r/eugen/dev-tools
sudo apt update
sudo apt install my-package

To see managed sources without changing them, run tparun installed --verbose.

Publish a package

Publishing is an account action. The repository owner remains responsible for the package and its provenance.

tparun login https://tpa.run
tparun create my-repo
tparun stage ./my-package_1.0.0_amd64.deb
tparun status
tparun publish https://tpa.run/r/you/my-repo

Read the status output before confirming publication. Set repository visibility separately and intentionally.

Use a private repository

Ask the publisher for a reader credential, then add the repository. The credential authorizes package downloads from that repository only.

sudo tparun add https://tpa.run/r/you/private-tools

Enter the repository password when prompted. Keep it out of shell history and shared configuration.
