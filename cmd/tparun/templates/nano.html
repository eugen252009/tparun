If a package exceeds your available storage or technical publication limits, it cannot be published. Standard and Pro are planned, not currently available upgrades.

Recipes are optional.

Mema is an independent installation and version-management tool. A recipe can tell Mema how to retrieve software from its existing upstream.

  1. Host the recipeTPA.run distributes the small signed Debian package.
  2. Retrieve the softwareMema downloads the application from its upstream source.
  3. Use the upstream trust modelMema uses that source's availability and trust model for the application download; TPA.run hosts the recipe package.

This keeps a large application payload at its existing upstream. The Mema runtime is a separate package installed on the consumer's machine.

Estimate with your own packages.

At roughly 2 KB per recipe package, 5 MB is approximately 2,500 packages before other published payloads. Real packages vary, and the runtime also needs space if you host it yourself.

Illustration only—not a package-count promise. Download frequency, APT metadata, caching, and package sizes affect egress.
