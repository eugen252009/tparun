What counts toward capacity?

Storage

The canonical published .deb payloads across your repositories. Repository metadata and temporary workspaces are excluded from this measurement.

Publishing is subject to entitlement and technical upload limits.

Repository egress

Package and repository metadata bytes actually delivered. Nano uses an annual entitlement period. After its allowance, new package downloads are rate-limited rather than abruptly cutting off active transfers.

Uploads remain subject to technical rate and request limits. Read the usage details.
